# What is this project?

This is a personal project I spun up specifically to practice creating a backend and utilizing tools I haven't used before or have little experience with. ***This project is not intended to use the most efficient solutions*** but to serve an educational exercise for backend development and tools I don't have significant experience with.

I chose to build a collection management tool as I wanted to build something I would actually have a reason to use. As an avid collector of many things, I wanted a way to track my collections should I ever need the record for insurance purposes.

# What are you tools are you using?

### Libraries that are (relatively) new to me:
(Some may not yet be implemented, but I intend to use them all)

| Tool/Library                                                                           | Thoughts                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Neon](https://neon.com/) - Postgres Database                                          | This was really simple to setup and worked flawlessly. No complaints!                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [Drizzle](https://orm.drizzle.team/) - ORM for interfacing with DB                     | I'm honestly split on this one. I think it does a great for what it's meant for, and the release candidate branch for relational queries is worth utilizing, but I think the exact reason I chose this tool actually may have done more harm than good, which is that you can write SQL in TS. I think being forced to write raw SQL may have been a better option in the long-run as I would have developed a better understanding of how to write SQL queries and the proper way to structure everything.                                                         |
| [Zod](https://zod.dev/) - Schema validation                                            | I personally feel like [Yup](https://github.com/jquense/yup) is a better option for form validation, but its schema validates asynchronously by default, which was a problem with TanStack Form (At least in V1 when I started. Not sure about v2 alpha). It's a a great, simple validation tool, and my only problem is the error messaging which I think Yup does a far better job of handling. At time of writing, Yup hasn't been updated in a long time, and I hope it's not abandoned as it's a top notch validator!                                          |
| [Swagger](https://swagger.io/) - API documentation                                     | *Coming soon*                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [Better-Auth](https://better-auth.com/) - User authentication                          | Fantastic authentication library. I think some of their property names could stand to be clarified as they definitely caused some confusion for me during setup, but otherwise it's fantastic!                                                                                                                                                                                                                                                                                                                                                                      |
| [Resend](https://resend.com/docs/introduction) - Authentication emails                 | Wonderful, simple tool for handling simple emails. I had no issues getting this setup.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| [Material Base UI](https://base-ui.com/react/overview/about) - React Component Library | Overall a pretty solid UI component library. While it's certainly more work, I much prefer using the Base UI library with Tailwind over the full Material UI library which feels too restrictive.                                                                                                                                                                                                                                                                                                                                                                   |
| [Tailwind CSS](https://tailwindcss.com/) - Atomic CSS library                          | I have used (and even written) atomic CSS libraries before, so this isn't anything new in concept, but I haven't truly utilized Tailwind specifically before. I found it nice and simple, and when paired with [Tailwind Merge](https://www.npmjs.com/package/tailwind-merge) You can really use it to it's full extend. That said, I think looking at a lot of classes can make it difficult to see what styles are being applied at a glance. I think I prefer something closer to Styled Components, but this is still a fantastic CSS library.                  |
| [TanStack Start](https://tanstack.com/start/latest) - Fullstack framework              | There was definitely a bit of a learning curve for me on this one, but I thin it works really well, and I would recommend it. That said, I miss the days when everything was done client-side, lol.                                                                                                                                                                                                                                                                                                                                                                 |
| [TanStack Router](https://tanstack.com/router/latest) - Fullstack framework routing    | I think this works great! It can feel difficult ot tell where Tanstack Start ends and Tanstack Router begins sometimes, but I had zero issues with this library.                                                                                                                                                                                                                                                                                                                                                                                                    |
| [TanStack Form](https://tanstack.com/form/latest) - Headless Forms UI                  | At first I was fighting this library with every line of code that I wrote, but once the v2 alpha become available, that all changed. It was a big breaking change, but it made things SO much easier to work with and I feel like this is a great library now. I'm looking forward ot the full v2 release!                                                                                                                                                                                                                                                          |
| [TanStack Hotkeys](https://tanstack.com/hotkeys/latest) - Keyboard shortcuts           | This is a fantastic library for adding hotkey support! Trying to come up with hotkeys that would feel intuitive but also not be overridden by the browser was the biggest challenge here.                                                                                                                                                                                                                                                                                                                                                                           |
| [TanStack Store](https://tanstack.com/store/latest) - Global State Management          | This library works great, and provides atom support which helped me since I was coming off of Jotai for global state management                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [Vite](https://vite.dev/) - Build tool                                                 | No issues here, but I don't often spin up brand new projects from scratch. It works well!                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [Vitest](https://vitest.dev/) - Testing framework                                      | *Coming soon*                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [Zustand](https://zustand.docs.pmnd.rs/) - React state library                         | I wasn't too fond of Zustand and had a lot of issues with it, but I think that's part of me coming from Jotai and having a hard time at first with the "store" structure. I was trying to force Zustand into the Jotai box, and it just doesn't fit. I ended up converting everything over to [TanStack Store](https://tanstack.com/store/latest), which worked great, but the two libraries are very similar and I think if I had just rewritten my previous Zustand implementation to match the final Tanstack Store implementation it would end up very similar. |

# Anything else?

### I've used these libraries before, but I feel like they're worth calling out since I'm using so much else by TanStack:

| Tool/Library                                                                                       | Thoughts                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [TanStack Query](https://tanstack.com/query/latest) - Async state management                       | Unless you're using Apollo GraphQL which has it's own async state management, I can't fathom why wouldn't use this library. An absolute must-have, in my opinion!                                          |
| [TanStack Table](https://tanstack.com/table/latest) - Headless UI for building tables              | Another must-have library if your'e building out React tables. I haven't used anything better!                                                                                                             |
| [TanStack Dev Tools](https://tanstack.com/devtools/latest) - Devtools panel for TanStack libraries | Huge props to the folks at Tanstack for building these tools for us devs to help troubleshoot their libraries. If you're using any Tanstack library that has its own dev tools, you NEED to be using them! |
